# Support LT Tracker

Mini application web (statique) pour suivre des actions avec :

- support long terme,
- cours actuel,
- écart en euros,
- écart en pourcentage.

## Lancer

Ouvrez simplement `index.html` dans votre navigateur.

## Utilisation

1. Remplissez le formulaire "Ajouter une action".
2. Cliquez sur **Ajouter**.
3. Utilisez la barre de recherche pour filtrer rapidement.
4. Supprimez une ligne avec **Supprimer**.

Les données sont conservées dans le `localStorage` du navigateur.
